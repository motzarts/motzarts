## 👋 About Me

I'm **Morteza Shokri** — a developer focused on building useful web products and practical digital solutions. My work and learning span modern full-stack development, workflow automation, and hands-on IT infrastructure.

- 💻 Building across the stack with **JavaScript, TypeScript, React, Next.js, Node.js, and NestJS**.
- 🗄️ Interested in robust data layers with **PostgreSQL, SQL, and Drizzle ORM**.
- ⚙️ Exploring **n8n** and automation to make everyday processes simpler and more reliable.
- 🖧 Also work with and learn about **networking, hardware, and CCTV systems**.
- 🚀 Developing the **Jam Techno** initiative: [jamtechno.ir](https://jamtechno.ir) · [Telegram](https://t.me/jam_techno)

> I like turning ideas into dependable solutions—then improving them through real-world use.
